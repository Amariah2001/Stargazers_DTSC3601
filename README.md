<h3> About Our Project </h3>
<p> Our project is the Stargazing Quality Predictor, which will use a combination of humidity, temperature, and visibility to determine the most likely quality of stargazing the next night. The project is useful because it will help anyone from an amateur level to possibly experts determine if the next night is a good night to stargaze or not. This can reduce near-misses of seeing an astrological event occurring, and gives people time to plan, if needed. </p>
